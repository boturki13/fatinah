# قائمة تحقق إصدار فطنة

استخدم البنود المناسبة للتغيير، واستخدمها كلها قبل وصف البناء بأنه جاهز لـTestFlight أو App Store.

## المحتوى

- شغّل `npm run questions:audit`.
- تأكد أن المنشور معتمد، بلا تكرار أو شبه تكرار، وله مستوى ومصدر دقيق.
- راجع الفئات الدينية يدوياً ولا تعتمد نتيجة النموذج وحدها.
- تأكد أن التطبيق لا يستدعي OpenAI أو Claude وقت اللعب.

## السلوك والاشتراك

- اختبر الجولة المجانية: حساب جديد، إكمال كامل، خروج مبكر، إعادة فتح، جهاز ثانٍ، وانقطاع الشبكة.
- اختبر عدم ظهور الاشتراك قبل الجولة، وظهوره بعدها، ودخول المشترك النشط مباشرة.
- اختبر شراء الشهري والسنوي، الإلغاء، الفشل، الاستعادة، وتأخر RevenueCat.
- اختبر Apple Offer Code على Sandbox/TestFlight بعد إنشائه في App Store Connect.
- اختبر عدم تكرار السؤال داخل الجولة وعبر جولتين للحساب نفسه.

## الحساب والبلاغات والقياسات

- اختبر الإبلاغ مع سبب صحيح، مدخل مرفوض، حد الطلبات، تعطل SMTP، وإعادة المحاولة.
- تحقق أن البلاغ يصل فعلياً إلى `ata@ata20.com` في بيئة الاختبار قبل الإنتاج.
- تأكد أن القياسات لا تحتوي نص السؤال أو البريد أو الاسم أو token.
- اختبر حذف الحساب ثم إعادة فتح التطبيق والدخول بحساب آخر، وتأكد من فصل RevenueCat وحذف البيانات التابعة.

## الاختبارات والبناء

من جذر المشروع:

```bash
node --check www/app.js
python3 -m py_compile server.py
npm test
npx cap sync ios
xcodebuild -workspace ios/App/App.xcworkspace \
  -scheme App -configuration Release \
  -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO build
git diff --check
```

- بعد المزامنة، قارن `www/app.js` و`www/index.html` و`www/app.css` مع `ios/App/App/public/`.
- افحص الحزمة العامة بحثاً عن `OPENAI_API_KEY` أو `sk-` أو كلمات مرور SMTP أو أسرار webhook.
- تحقق من `PrivacyInfo.xcprivacy` ومن إدراجه في موارد هدف iOS.
- راجع رقم الإصدار ورقم البناء وهدف iOS، ولا تغيّرها تلقائياً.

## إعدادات خارج الكود

- نشر الخادم الجديد وتهيئة أسرار SMTP.
- إنشاء Apple Subscription Offer Code وتحديد الأهلية والمدة والحدود.
- تحديث App Store Connect Privacy وبيانات الإصدار ولقطات الشاشة عند الحاجة.
- تجربة البناء على TestFlight بحساب جديد ومشترك وحساب انتهى اشتراكه.

اذكر هذه العناصر كإعدادات معلقة إذا لم تُنفذ فعلياً. نجاح البناء المحلي لا يثبت وصول البريد أو نشر الخادم أو تفعيل كود Apple.
