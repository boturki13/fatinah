# شروط المنتج والمحتوى في فطنة

## نطاق المنتج الحالي

- العربية هي اللغة الوحيدة في المرحلة الحالية.
- المؤجل حتى طلب جديد: الإنجليزية، وضع الأطفال، وتحدي الأسبوع.
- حافظ على تجربة لعبة جماعية واضحة ومتجانسة، ولا تغيّر قواعد احتساب النقاط أو عدد مستويات الفئة بلا سبب واختبارات.

## الأسئلة والفئات

- كل فئة منشورة تحتوي تغطية للمستويات `1` إلى `6`، وتزداد المعرفة أو الاستدلال المطلوب تدريجياً.
- السؤال واضح، مباشر، غير ملتبس، وله جواب واحد مقبول أو قائمة أجوبة مقبولة محددة.
- لا تستخدم سؤالاً خادعاً يعتمد على صياغة مبهمة، ولا معلومة سريعة التقادم دون تاريخ أو سياق.
- أعطِ كل سؤال معرفاً ثابتاً، وفئة، ومستوى، ومصدراً دقيقاً، وحالة مراجعة.
- افحص التطابق النصي وشبه التطابق والمعنى المتكرر قبل الاعتماد.
- الفئات الجديدة يجب أن تكون مميزة عن الموجود فعلاً، لا مجرد إعادة تسمية لموضوع قائم.
- الجولة الواحدة تختار من البنك المنشور المعتمد فقط؛ لا يوجد مسار توليد حي أو fallback إلى سؤال غير مراجع.

## اختيار المصادر

- فضّل المصدر الأولي الرسمي: جهة حكومية، منظمة دولية، اتحاد رياضي رسمي، مؤسسة علمية، جامعة، متحف، أو ناشر العمل الأصلي.
- استخدم مرجعاً عالمياً موثوقاً عند غياب المصدر الأولي، وتجنب المدونات المجهولة ومحتوى المستخدمين كمصدر وحيد.
- يجب أن يثبت الرابط الادعاء نفسه، لا أن يكون الصفحة الرئيسية العامة فقط.
- للموضوع المتغير زمنياً، دوّن تاريخ التحقق وحدد السنة أو النسخة داخل السؤال عند الحاجة.

## المحتوى الديني والتاريخ الإسلامي

- القرآن: استشهد بالسورة والآية، واستخدم نصاً قرآنياً موثوقاً وتفسير ابن كثير عند الحاجة إلى التفسير.
- الحديث: استخدم الحديث الصحيح، وفضّل صحيح البخاري أو صحيح مسلم، مع رابط الحديث أو رقمه وحكمه. لا تنسب حديثاً للنبي ﷺ اعتماداً على نموذج ذكاء اصطناعي.
- السيرة والصحابة والتاريخ: يمكن الرجوع إلى المصادر المعتبرة مثل ابن كثير والطبري، لكن الرواية التاريخية لا تصبح صحيحة الإسناد لمجرد ورودها فيهما. افحص الإسناد أو أي نقد علمي متعلق بالرواية، وقدّم ما ثبت بلا مبالغة.
- عند تعارض المصادر أو غياب إثبات واضح، ارفض السؤال ولا تنشره.
- كل سؤال ديني يبقى `pending_religious_review` حتى يقرّ مراجع بشري صراحة صحة المصدر والإسناد.
- لا تصدر فتاوى، ولا تجعل الخلاف الفقهي جواباً قطعياً، ولا تدخل أسئلة خلافية حساسة في جولة عامة بلا صياغة وسياق مناسبين.

## مصنع المحتوى الإداري

المسار المقبول هو: توليد مرشحين خارج التطبيق، إرفاق المصادر، تحقق مستقل، كشف التكرار، مراجعة بشرية، ثم نشر إلى البنك المعتمد. استخدم أوامر المشروع الحالية:

```bash
npm run questions:generate -- --category "اسم الفئة" --difficulty balanced --count 24
npm run questions:review -- --id gq-... --decision approve --reviewer "اسم المراجع"
npm run questions:review -- --id gq-... --decision approve --reviewer "اسم المراجع" --religious-confirmed
npm run questions:publish
npm run questions:audit
```

لا تشغّل توليداً مدفوعاً دون التأكد من وجود مفتاح إداري آمن وموافقة المستخدم على التكلفة المطلوبة.

## الجولة والاشتراك

- الجولة المجانية واحدة كاملة لكل Firebase UID، مع حالة خادمية ومؤشر محلي للعمل دون اتصال.
- الخروج قبل اكتمال الجولة لا يستهلكها. اكتمالها يُسجل بطريقة idempotent حتى لا تتكرر المعاملة.
- المشترك النشط يدخل مباشرة إلى اللعبة. غير المشترك الذي أنهى الجولة يرى الاشتراك عند محاولة المتابعة.
- الاستعادة والشراء وتحديث الاستحقاق تأتي من Apple/RevenueCat، ويجب اختبار النجاح والإلغاء والفشل وتأخر الشبكة.
- العروض المجانية للأصدقاء تُدار من App Store Connect وتُسترد عبر واجهة Apple الرسمية.

## البلاغات والقياسات

- البلاغ يحفظ معرف السؤال وفئته ونصه وجوابه وسبب البلاغ وتفصيل المستخدم عند وجوده، مع حدود طول وقائمة أسباب مسموحة.
- لا تُظهر البريد المستلم أو إعدادات SMTP للمستخدم، ولا تسمح بحقن رؤوس البريد.
- فشل SMTP لا يفقد البلاغ: يبقى بحالة قابلة لإعادة المحاولة.
- القياسات مسموحة بقائمة أحداث محددة وخصائص منتجات غير شخصية؛ لا ترسل نصوص الأسئلة أو البريد أو رموز الدخول.
- احمِ ملخص القياسات الإداري بسر خادمي، وطبّق تحديد المعدل وحدود حجم الطلب.

## الأمان والخصوصية

- مفاتيح OpenAI وSMTP وRevenueCat webhook وFirebase Admin أسرار خادمية/إدارية ولا تدخل الحزمة العامة.
- تحقق من Firebase ID token على الخادم لكل بيانات مرتبطة بالحساب.
- استخدم HTTPS، تحقق مدخلات صارماً، استعلامات SQL ممررة، وحدود طلبات وأحجام مناسبة.
- لا تسجل tokens أو كلمات المرور أو الأسرار في السجلات وCrashlytics.
- حدّث سياسة الخصوصية وملف Apple Privacy Manifest وإفصاحات App Store عند تغير جمع البيانات.
