---
name: Git synchronization
description: التعامل مع تعارضات السحب الظاهرية عند مزامنة فرع main مع GitHub
---

إذا أبلغت أداة السحب عن `MERGE_CONFLICT` بينما لا توجد ملفات غير مدمجة ولا تغييرات معلّقة، استخدم `git fetch origin main` ثم افحص الفرق بين الفرعين وادمج `origin/main` يدوياً. هذا يحافظ على commits المحلية ولا يستبدلها قسراً.

**Why:** قد تكون حالة الدمج المحلية سليمة رغم أن عملية السحب الآلية توقفت بخطأ تعارض عابر.

**How to apply:** تحقّق دائماً من `git status` و`git ls-files -u` قبل أي إلغاء دمج أو reset.
