# مرشح إصدار فطنة 1.4.0

> أصبح `release/current.json` مصدر حقيقة مرشح الإصدار `1.4.0`،
> وMarketing Version رقم `1.4`، والبناء `17`. البناء 16 متجاوز بعد
> إصلاحات ما قبل الإطلاق؛ لم يُنشأ tag ولم يُرفع التطبيق بعد. خادم 1.4
> منشور، لكن فئات الصور تبقى بوابة إطلاق حمراء حتى نشر أصولها والتحقق منها.

## حدود العزل

- الإصدار 1.3 (البناء 9) يبقى مرجع الإصدار السابق ولا تُعدّل حزمته المنشورة.
- كل عمل جديد يتم على `codex/develop-1.4.0` أو فروع ميزة خارجة منه.
- لا يُعاد نشر Replit production أثناء تطوير 1.4؛ يستخدم staging وfeature flags فقط.
- لا يُرفع أي Archive باسم 1.4 قبل اكتمال Release Candidate وقائمة التحقق.

## نقطة البداية

- Marketing Version: `1.4`.
- Package Version: `1.4.0`.
- Build: `17`، وهو المرشح التالي بعد إصلاحات تدقيق ما قبل الإطلاق.
- لم يُنشأ tag ولم يُرفع التطبيق بعد. يجب أولاً نجاح CI وXCUITest، ونشر
  أصول الصور، ثم TestFlight على جهاز حقيقي.

## عقد بنك الأسئلة في 1.4

- 33 فئة نصية و2,892 سؤالًا نصيًا، بالإضافة إلى 7 فئات صور و300 سؤال مصور.
- كل سؤال يحتوي أربعة خيارات وإجابة صحيحة واحدة، موزعة على ستة مستويات.
- الفئات `رتّبها صح` و`رياضيات وحساب` و`ألغاز بوليسية` ملغاة، ويرفضها المولّد والخادم والعميل.
- التطبيق لا يشحن بنكًا احتياطيًا؛ الكتالوج والجولة وكشف الإجابة تأتي من API v2 فقط.
