# مرشح إصدار فطنة 1.4.0

> أصبح `release/current.json` مصدر حقيقة مرشح الإصدار `1.4.0`،
> وMarketing Version رقم `1.4`، والبناء `17`. لم يُنشأ tag ولم يُرفع التطبيق
> بعد. التغييرات الحالية محلية ولم تُنشر؛ بنك 1.4 الجديد ما زال فارغاً عمداً.

## حدود العزل

- الإصدار 1.3 (البناء 9) يبقى مرجع الإصدار السابق ولا تُعدّل حزمته المنشورة.
- كل عمل جديد يتم على `codex/develop-1.4.0` أو فروع ميزة خارجة منه.
- لا يُعاد نشر Replit production أثناء تطوير 1.4؛ يستخدم staging وfeature flags فقط.
- لا يُرفع أي Archive باسم 1.4 قبل اكتمال Release Candidate وقائمة التحقق.

## نقطة البداية

- Marketing Version: `1.4`.
- Package Version: `1.4.0`.
- Build: `17`، وهو المرشح التالي بعد إصلاحات تدقيق ما قبل الإطلاق.
- لم يُنشأ tag ولم يُرفع التطبيق بعد. يجب أولاً نجاح CI وXCUITest، واعتماد
  600 سؤال موثق، ثم TestFlight على جهاز حقيقي.

## عقد بنك الأسئلة في 1.4

- لا توجد فئات أو شاشة فئات. البنك القديم وكل أصوله محذوفة.
- البداية المطلوبة 600 سؤال نصي موثق: 100 سؤال معتمد لكل مستوى من ستة مستويات.
- كل سؤال أربعة خيارات وإجابة واحدة، ومصادر وأسباب داخلية لا تصل إلى واجهة اللاعب.
- يحتفظ جهاز المشترك دائماً بحزمتين قادمتين مشفرتين ويعوضهما في الخلفية؛
  الحساب المجاني يتلقى حزمة الجولة التعريفية الوحيدة فقط.
- منع التكرار مرتبط بالحساب على كل أجهزته، ويعاد المستوى فقط بعد استهلاك بنكه.
- لا تستهلك الجولة المجانية إذا لم يجتز البنك بوابة الجاهزية.
