# قائمة تحقق الإصدار

## المصدر

- [ ] فرع الإصدار منشأ من commit معروف وworktree نظيف.
- [ ] `release/current.json` مطابق لـ`package.json` وXcode.
- [ ] `sourceCommit` يطابق commit المرشح و`artifactSha256` تطابق Archive.
- [ ] `CHANGELOG.md` مكتمل ولا يحتوي عناصر غير منجزة.
- [ ] لا توجد أسرار أو ملفات أكبر من سياسة المستودع.
- [ ] CI أخضر والمراجعة معتمدة.

## الاختبار

- [ ] `npm test` ناجح والبنك القديم وأزرار الفئات غير موجودة في حزمة الويب وiOS.
- [ ] لوحة الجودة تعرض 100 سؤال معتمد على الأقل لكل مستوى (600 إجمالاً).
- [ ] عينة تدقيق مستقلة للمصادر والصياغة والإجابة اجتازت المراجعة قبل الدمج.
- [ ] اختبارات Xcode/Swift ناجحة.
- [ ] Archive Release لجهاز حقيقي ناجح.
- [ ] TestFlight على جهازين وإصدارَي iOS مدعومين على الأقل.
- [ ] VoiceOver وDynamic Type والشبكة الضعيفة اختُبرت.
- [ ] شريط QA يظهر فقط في loopback preview، ورسائل الجولة المجانية تميّز الأوفلاين عن فشل الخدمة.
- [ ] جولة من 1 و2 و3 لاعبين تثبت التناوب، 30 ثانية، أولوية النقاط وعدم كشف الحل.
- [ ] حزمة الجهاز مشفرة، والعبث أو اختلاف الحساب يرفضان فكها، والتعويض بالخلفية يعمل.
- [ ] وسائل المساعدة الأربع مرة واحدة لكل لاعب، ومنها دبل النقاط بالسالب عند الخطأ.

## الخادم

- [ ] إعدادات staging منفصلة عن production.
- [ ] بوابة الإنتاج تعرض `ready: true` و`failed_checks: []`.
- [ ] النسخ الاحتياطي وخطة الرجوع موثقان.
- [ ] smoke test للرابط والحساب والشراء والحزم ولوحة الجودة والبلاغات ناجح.
- [ ] لا تظهر قيم حساسة في السجلات.

## App Store

- [ ] Marketing Version ورقم البناء صحيحان.
- [ ] PrivacyInfo وبيانات الخصوصية متطابقة.
- [ ] Screenshots والوصف وملاحظات المراجعة محدثة.
- [ ] حساب المراجعة يعمل.
- [ ] البناء الصحيح مرتبط بالإصدار.
- [ ] طريقة الطرح: تدريجي أو يدوي، محددة مسبقًا.

## بعد الإطلاق

- [ ] مراقبة الأعطال والأداء والبلاغات أول 24 ساعة.
- [ ] مراجعة مؤشرات الشراء والاستعادة والحذف والجولة المجانية.
- [ ] إغلاق release notes وربط tag وdeployment والبناء.
- [ ] بدء فرع التحديث التالي من tag المعتمد.
